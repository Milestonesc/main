# Hermes Calendar

헤르메스 에이전트에게 말로 전한 개인 일정을 구글 캘린더에 넣고, 한국 공휴일·연차를 반영해서 알려주는 도구입니다. 일정마다 진행 상태와 메모·할 일·기록이 남아서, 지난 일정이 어떻게 됐는지 나중에도 볼 수 있습니다.

- **일정 등록·조회·수정·삭제**: 헤르메스 전용 'Hermes' 캘린더에 넣고, 조회와 겹침 확인은 기본 캘린더까지 함께 봅니다.
- **쉬는 날 계산**: 주말, 법정공휴일(설·추석, 대체공휴일, 선거일, 임시공휴일), 근로자의 날, 내 연차·휴가 일정.
- **상태 기록**: 예정 · ▶️ 진행중 · ⏳ 지연됨 · ✅ 완료 · ❗ 못함 · ❌ 취소. 바뀔 때마다 시각과 함께 기록됩니다.
- **설명·메모·할 일**: 일정마다 짧은 설명, 날짜가 붙어 쌓이는 메모, 체크하는 할 일.
- **겹침 경고**: 새 일정이 기존 일정과 겹치면 바로 넣지 않고 먼저 물어봅니다.
- **영업일·D-day**: "영업일 7일 뒤가 언제야?", "시험까지 며칠?"
- **아침 브리핑**: 매일 08:30 텔레그램으로. 결과가 안 남은 지난 일정도 함께 알려줍니다.
- **직전 알림**: 등록할 때 "30분 전에 알려줘"라고 한 일정만 텔레그램으로. 말하지 않은 일정은 알림이 없습니다.

브리핑과 알림은 헤르메스의 스크립트 크론으로 돌아서 LLM 토큰을 쓰지 않습니다.

```
📅 9월 22일 (화) 브리핑

• 10:00–11:00 팀 주간회의
• 10:30–11:30 치과 @강남역 (할 일 1/2) ⏰
• 12:00–13:00 ⏳ 보고서 마감
• 19:00–20:00 PT
⚠️ 겹침: 10:00 팀 주간회의 ↔ 10:30 치과

내일(수) 일정 1개, 첫 일정 12:00–13:00 엄마랑 점심
🗓 다가오는 쉬는 날: 9/24(목) 추석 전날, 9/25(금) 추석, 9/26(토) 추석 다음날, 9/28(월) 연차, 10/3(토) 개천절, 10/5(월) 개천절 대체 휴일
🎯 정보처리기사 시험 D-60 (11/21)

📝 결과가 안 남은 지난 일정 1개 — "치과 완료"처럼 알려주세요
• 9/19(토) 07:00–08:00 헬스
```

## 설치

헤르메스가 돌아가는 컴퓨터에서 진행합니다. 헤르메스에 텔레그램이 연결돼 있어야 브리핑·알림이 옵니다.

### 윈도우

1. `hermes-calendar` 폴더를 받아서 압축을 풉니다. (GitHub 페이지의 초록색 **Code → Download ZIP**, 또는 Claude가 보내준 zip 파일)
2. 폴더 안의 **`install.cmd`를 더블클릭**합니다. "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행**.
3. 창에 나오는 안내대로 따라 하면 됩니다.
   - 파이썬이 없으면 자동으로 설치합니다.
   - 구글 클라우드 화면이 열리면 안내된 5단계를 눌러 파일 하나를 받습니다. 받으면 다운로드 폴더에서 저절로 찾아서 다음으로 넘어갑니다.
   - 구글 로그인 화면에서 내 계정을 고르고 허용합니다. "Google에서 확인하지 않은 앱"이 나오면 **고급 → (프로젝트 이름)(으)로 이동**. 내가 만든 앱이라 괜찮습니다.
   - 헤르메스 등록·크론 등록·재시작은 자동입니다.
4. 텔레그램에서 헤르메스에게 "오늘 일정 알려줘"라고 보내 봅니다.

중간에 멈추거나 창을 닫았으면 `install.cmd`를 다시 실행하세요. 끝난 단계는 건너뜁니다.

### 리눅스·맥 (미니PC 등)

```bash
bash install.sh
```

화면 없는 서버에서는 구글 로그인 링크가 출력됩니다. 휴대폰이나 다른 PC에서 열고 로그인한 뒤, 열리지 않는 `http://localhost:1/?...` 페이지의 주소를 통째로 복사해 붙여넣으면 됩니다. 구글 클라우드 파일(`client_secret_....json`)은 `~/Downloads/`에 두면 찾아갑니다.

### 직접 하고 싶다면

설치 스크립트가 하는 일은 이것뿐입니다.

```bash
python -m venv <hcal 폴더>/venv
<hcal 폴더>/venv/bin/pip install .          # 윈도우: venv\Scripts\pip
hcal setup                                  # 구글 파일 받기 안내 + 로그인 + 'Hermes' 캘린더 만들기
hcal install-hermes --apply                 # 헤르메스 스킬·MCP·크론 등록, 재시작
```

`hcal` 폴더는 윈도우 `%LOCALAPPDATA%\hermes\hcal`, 리눅스·맥 `~/.hermes/hcal`입니다. `--apply` 없이 실행하면 헤르메스에 직접 넣을 명령을 보여줍니다. 브리핑 시간은 `--brief-time "0 7 * * *"`처럼 바꿀 수 있습니다.

## 이렇게 말하면 됩니다

| 말 | 헤르메스가 하는 일 |
|---|---|
| 내일 3시 강남역 치과, 30분 전에 알려줘 | 15:00–16:00 등록 + 14:30 텔레그램 알림 |
| 금요일 7시 저녁 약속 | 등록만 (알림 없음) |
| 다음주 수~금 연차 | 종일 일정 3일, 쉬는 날·영업일 계산에 반영 |
| 매주 화요일 7시 PT | 반복 일정 |
| 11월 21일 정보처리기사 시험, 디데이로 보여줘 | 아침 브리핑에 `D-30` 표시 |
| 엄마 생일 10월 23일, 하루 전에 알려줘 | 종일 일정, 전날 09:00 알림 |
| 치과 1시간 뒤로 미뤄줘 | 길이는 유지하고 시간만 이동 |
| 치과 알림 꺼줘 / PT에 10분 전 알림 추가해줘 | 알림만 변경 |
| 계약서 영업일 7일 안에 보내야 해, 마감 언제야? | 주말·공휴일·연차를 뺀 날짜 |
| 10월 9일 쉬는 날이야? | 한글날 |
| 다음주에 뭐 있어? / 치과 언제였지? | 기간 조회 / 검색 |

새 일정이 기존 일정과 겹치면 헤르메스가 겹치는 일정을 보여주고 그래도 넣을지 묻습니다.

### 상태·메모·할 일

| 말 | 헤르메스가 하는 일 |
|---|---|
| 치과 다녀왔어, 다음 진료 10월 6일 | ✅ 완료 + 기록에 "다음 진료 10/6" |
| 회의가 4시로 밀렸어 | ⏳ 지연됨 + 일정을 4시로 옮기고 기록에 "지연 15:00 → 16:00" |
| 회의 4시로 옮겨줘 | 시간만 옮기고 기록에 "시간 변경" (내가 바꾼 것과 밀린 것을 구분) |
| 지금 보고서 쓰는 중 | ▶️ 진행중 |
| 오늘 헬스 못 갔어 | ❗ 못함 |
| 금요일 약속 취소됐어 | ❌ 취소 (지우지 않고 남김, 그 시간은 비어 있는 것으로 계산) |
| 치과는 사랑니 상담이야 | 설명 추가 |
| 치과에 메모: 사진 다시 찍자고 함 | 메모 추가 (날짜 자동) |
| 여행 준비물에 여권, 충전기 추가 / 여권 챙겼어 | 할 일 추가 / 체크 |
| 치과 자세히 보여줘 | 상태·설명·할 일·메모·기록 전체 |
| 이번 달 어땠어? / 이번 주 못한 거 뭐 있어? | 상태별 개수와 못함·지연 목록 |

생일·기념일·연차처럼 '하는 일'이 아닌 일정은 지난 뒤 결과를 묻지 않습니다.

모든 내용은 일정 설명란에 저장되고 제목 앞에 상태 표시가 붙어서, 폰의 구글 캘린더 앱에서도 이렇게 보입니다.

```
✅ 치과
─────────────
사랑니 상담

[할 일]
☑ 보험증 챙기기
☐ 다음 예약 잡기

[메모]
9/22 사진 다시 찍자고 함

[기록]
9/18 20:00 등록
9/22 11:40 완료 · 다음 진료 10/6
```

구글 캘린더 앱에서 설명란을 직접 고쳐도 됩니다. `[할 일]`, `[메모]`, `[기록]` 줄만 유지하면 헤르메스가 다시 읽습니다. 할 일은 `☐`/`☑` 대신 `[ ]`/`[x]`로 써도 됩니다.

## 설정 바꾸기

`hcal` 폴더(`credentials.json`이 있는 곳)의 `config.json`을 고칩니다. 없는 항목은 기본값을 씁니다.

```json
{
  "read_calendars": ["primary", "회사캘린더ID@group.calendar.google.com"],
  "may_day_off": true,
  "leave_keywords": ["연차", "휴가", "월차", "휴무"],
  "default_duration_minutes": 60
}
```

| 항목 | 뜻 |
|---|---|
| `read_calendars` | 브리핑·겹침 확인 때 함께 읽을 캘린더. 캘린더 ID는 구글 캘린더 설정 → 캘린더 통합에 있습니다 |
| `may_day_off` | 근로자의 날(5/1)을 쉬는 날로 계산 (2026년부터는 법정공휴일 '노동절'이라 항상 쉬는 날) |
| `leave_keywords` | 이 단어가 제목에 든 **종일** 일정을 쉬는 날로 계산. 반차처럼 시간이 있는 일정은 세지 않습니다 |
| `default_duration_minutes` | 길이를 말하지 않았을 때 일정 길이 |

## 미니PC 등 다른 컴퓨터로 옮길 때

1. 새 컴퓨터에 헤르메스를 설치하고 텔레그램을 연결합니다.
2. 예전 컴퓨터의 `hcal` 폴더에서 `credentials.json`, `token.json`, `config.json` 세 파일을 새 컴퓨터의 `hcal` 폴더(리눅스 `~/.hermes/hcal/`)로 복사합니다. `venv` 폴더는 복사하지 않습니다.
3. 새 컴퓨터에서 설치 스크립트(`install.sh` 또는 `install.cmd`)를 실행합니다. 구글 로그인은 건너뜁니다.

## 명령어

헤르메스 없이 터미널에서도 쓸 수 있습니다. 모든 명령에 `--json`을 붙이면 기계용 출력이 나옵니다.

```bash
hcal add "치과" --start "2026-10-23 15:00" --location 강남역 --remind 30
hcal add "연차" --start 2026-10-28 --end 2026-10-30
hcal add "PT" --start "2026-10-27 19:00" --repeat weekly
hcal list                      # 오늘부터 7일
hcal list --date 2026-10-23
hcal list -q 치과 --days 90
hcal update <id> --start "2026-10-23 16:00"
hcal update <id> --remind 1h,10m   # 알림 추가·변경
hcal update <id> --no-remind
hcal add "여행" --start 2026-10-30 --desc "부산 1박" --todo 여권 --todo 충전기
hcal status <id> 완료 --note "다음 진료 11/6"     # 예정 진행중 지연됨 완료 못함 취소
hcal status <id> 지연됨 --start "2026-10-23 16:00" --note "상대 늦음"
hcal note <id> --memo "사진 다시" --check 1 --todo 우산 --remove 충전기
hcal show <id>                 # 설명·할 일·메모·기록
hcal review                    # 결과가 안 남은 지난 일정
hcal list --from 2026-10-01 --to 2026-10-31 --status 못함
hcal delete <id>               # 기록까지 사라짐. 남기려면 status 취소. 반복 전체는 --series
hcal day 2026-10-09            # 쉬는 날인지
hcal holidays --year 2027
hcal workday 2026-09-23 5      # 영업일 5일 뒤
hcal workdays 2026-10-01 2026-10-31
hcal dday 2026-12-25
hcal brief
```

알림 시점은 `30`(분), `30m`, `1h`, `1d`처럼 쓰고, 여러 개는 쉼표로 묶습니다(최대 30일 전). 종일 일정의 알림은 그날 09:00을 기준으로 계산합니다.

## 알아둘 점

- **알림은 헤르메스가 켜져 있을 때만 옵니다.** 노트북이 꺼져 있거나 잠들어 있으면 알림이 오지 않고, 깨어난 뒤 아직 시작 전인 일정은 그때 한 번 보냅니다. 늘 켜두는 미니PC가 있으면 더 안정적입니다.
- 이 도구로 넣은 일정은 구글 캘린더 앱 자체 알림을 꺼서 넣습니다. 텔레그램과 폰 알림이 두 번 울리지 않게 하려는 것입니다.
- 공휴일은 [holidays](https://pypi.org/project/holidays/) 라이브러리 기준입니다. 갑자기 정해진 임시공휴일은 구글 '대한민국의 휴일' 캘린더에서 보충하고, 라이브러리를 업데이트(`pip install -U holidays`)하면 반영됩니다.
- 반복 일정은 첫 회차만 겹침을 확인하고, 상태는 회차마다 따로 매깁니다.
- 일정을 삭제하면 기록도 함께 사라집니다. 기록을 남기려면 '취소'로 두세요.

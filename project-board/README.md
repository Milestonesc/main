# 프로젝트 현황판

10명 이하 사무실에서 함께 쓰는 프로젝트 일정·진행·비용 문서 공유 앱입니다. 공용 구글 계정 하나에 데이터를 모으고, 직원들은 바탕화면 아이콘으로 엽니다.

- **달력 · 타임라인**: 프로젝트 단계와 할 일 기한, 공휴일(대체공휴일 포함)을 한눈에
- **진행률**: 단계마다 구성원이 체크리스트를 넣고 체크하면 자동 계산
- **비용·문서**: 견적서·발주서·지출결의서·영수증 파일을 프로젝트별로 모으고, 증빙 없는 실비는 내용·금액만 입력. 전체 모아보기와 엑셀 내보내기
- **내 할 일**: 나에게 배정된 할 일과 내 프로젝트의 다가오는 마감
- **댓글 · 기록**: 프로젝트별 소식, 누가 언제 무엇을 바꿨는지 자동 기록
- **연동**: 단계 일정이 공용 구글 캘린더에 자동으로 들어가고, 평일 아침 9시쯤 바뀐 내용이 있을 때만 슬랙으로 알림. 그 주 첫 출근일엔 주간 요약도

권한 구분은 없습니다. 누구나 보고 고칠 수 있고, 대신 모든 변경이 기록에 남습니다.

## 어디에 무엇이 저장되나

공용 구글 계정의 드라이브에 **'프로젝트 현황판 문서'** 폴더가 생기고, 그 안에 전부 들어갑니다.

```
프로젝트 현황판 문서/
├─ 프로젝트 현황판 데이터   ← 구글 시트 (프로젝트·단계·할 일·비용·댓글·기록 탭)
├─ A사 홈페이지 리뉴얼/     ← 프로젝트마다 폴더, 올린 문서가 '날짜_종류_파일명'으로 저장
└─ B사 제품 촬영/
```

시트는 그대로 열어 볼 수 있어서 백업이나 엑셀 작업이 쉽습니다. 다만 시트에서 직접 고치면 기록에 남지 않으니, 고칠 때는 앱을 쓰세요.

## 설치 (공용 계정으로 한 번, 15분)

공용 구글 계정으로 로그인한 크롬에서 진행합니다.

### 1. 코드 붙여넣기

1. [script.google.com](https://script.google.com) → **새 프로젝트**. 왼쪽 위 '제목 없는 프로젝트'를 눌러 이름을 `프로젝트 현황판`으로 바꿉니다.
2. `Code.gs`에 있는 내용을 모두 지우고, 이 폴더의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣습니다.
3. 왼쪽 **파일 옆 +** → **HTML** → 이름을 `Index`로 짓고(`.html`은 자동으로 붙음), [`apps-script/Index.html`](apps-script/Index.html) 내용을 붙여넣습니다.
4. 왼쪽 **⚙ 프로젝트 설정** → **'편집기에서 appsscript.json 매니페스트 파일 표시'** 체크 → 편집기로 돌아가 `appsscript.json`을 열고 [`apps-script/appsscript.json`](apps-script/appsscript.json) 내용으로 바꿉니다.
5. 💾 저장(Ctrl+S).

### 2. 처음 준비 (setup 실행)

1. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **▶ 실행**.
2. 권한 창이 뜨면 공용 계정을 고르고 **허용**. "Google에서 확인하지 않은 앱"이 나오면 **고급 → 프로젝트 현황판(으)로 이동(안전하지 않음)** → 허용. 회사 계정이 직접 만든 앱이라 괜찮습니다.
3. 실행 로그에 `준비 완료`가 나오면 끝. 드라이브에 폴더·시트가, 구글 캘린더에 '프로젝트 현황판' 캘린더가 생깁니다.

### 3. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 유형 **웹 앱**.
2. **다음 사용자 인증 정보로 실행: 나(공용 계정)**, **액세스 권한이 있는 사용자: 모든 사용자** → **배포**.
3. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 둡니다. 이게 앱 주소입니다.

### 4. 처음 열기

1. 앱 주소를 엽니다. 처음엔 직원 이름을 한 줄에 한 명씩 적는 화면이 나옵니다.
2. 이름을 골라 들어가면 끝. 오른쪽 위 **⚙ 설정**에서 직원 목록, 팀 비밀번호, 슬랙을 바꿀 수 있습니다.

> 앱 주소를 아는 사람은 누구나 들어올 수 있습니다. 주소가 회사 밖으로 나갈 수 있다면 ⚙ 설정에서 **팀 비밀번호**를 하나 걸어 두세요.

### 5. 직원 PC에 바탕화면 아이콘 만들기

- **크롬**: 앱 주소 열기 → 오른쪽 위 **⋮ → 전송, 저장, 공유 → 바로가기 만들기** → **'창으로 열기'** 체크 → 만들기
- **엣지**: 앱 주소 열기 → **⋯ → 앱 → 이 사이트를 앱으로 설치**

직원은 구글 로그인이 필요 없습니다. 아이콘을 누르고 이름만 고르면 됩니다.

### 6. 슬랙 연결 (선택)

1. [api.slack.com/apps](https://api.slack.com/apps) → **Create New App → From scratch** → 이름 `프로젝트 현황판`, 회사 워크스페이스 선택.
2. 왼쪽 **Incoming Webhooks** → 켜기 → 아래 **Add New Webhook to Workspace** → 알림 받을 채널 선택 → 허용.
3. 생긴 **Webhook URL**(`https://hooks.slack.com/services/...`)을 복사해 앱의 **⚙ 설정 → 슬랙 알림**에 붙여넣고 저장 → **테스트**.

워크스페이스 설정에 따라 슬랙 관리자의 승인이 필요할 수 있습니다.

### 7. 직원 폰 캘린더에서 보기 (선택)

공용 계정의 [구글 캘린더](https://calendar.google.com) → 왼쪽 '프로젝트 현황판' 캘린더 **⋮ → 설정 및 공유**:
- 직원이 구글 계정이 있으면 **특정 사용자 또는 그룹과 공유**에 직원 이메일을 추가(권한: 모든 일정 세부정보 보기).
- 구글 계정이 없으면 같은 화면 아래 **iCal 형식의 비공개 주소**를 복사해 아이폰·아웃룩 캘린더에 '구독'으로 추가.

캘린더는 앱 → 캘린더 한 방향입니다. 캘린더에서 직접 고친 내용은 앱에 반영되지 않고, 다음에 앱에서 그 프로젝트를 고칠 때 앱 내용으로 덮어씁니다.

## 코드를 고쳤을 때 (주소 그대로 두기)

코드를 바꾼 뒤 **배포 → 배포 관리 → ✎(수정) → 버전: 새 버전 → 배포**. '새 배포'를 하면 주소가 바뀌니 주의하세요.

## 알아둘 점

- 슬랙 아침 알림은 9시 '쯤'(구글 예약 실행 특성상 9:00~9:15 사이) 갑니다. 주말과 공휴일은 건너뜁니다.
- 파일은 한 번에 40MB까지 올릴 수 있습니다. 그보다 큰 파일은 드라이브 프로젝트 폴더에 직접 넣고, 앱에는 내용·금액만 적어 두세요.
- 비용·문서를 지우면 파일은 드라이브 휴지통으로 가서 30일 안에 되살릴 수 있습니다. 프로젝트를 지워도 시트와 문서 폴더는 그대로 남습니다.
- 다른 사람이 고친 내용은 1분마다 자동으로 반영됩니다.
- 구글 앱스 스크립트 무료 한도(하루 실행 시간 등)는 10명이 쓰기에 충분합니다.

## 개발

구글 없이 이 컴퓨터에서 시험하는 도구가 `dev/`에 있습니다. 구글 서비스(시트·드라이브·캘린더·슬랙)는 `dev/mock.js`가 메모리에서 흉내 냅니다.

```bash
node dev/test.js                                   # 서버 코드 시험
npm pack fullcalendar@6.1.15 xlsx@0.18.5           # 미리보기용 라이브러리 (한 번)
node dev/build-preview.js <라이브러리 폴더>          # dev/out/index.html 미리보기 만들기
(cd dev/out && python3 -m http.server 8765)
XLSX_LIB=<xlsx 폴더> node dev/ui-test.js http://localhost:8765/index.html <스크린샷 폴더>   # 화면 시험 (Playwright)
```
